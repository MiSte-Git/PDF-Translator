# Lauf geprüft, kein automatischer CPU-Fallback bei unzureichender GPU).

# torch: WICHTIG - die generische PyPI-Version ist häufig die reine
# CPU-Variante. Für echte GPU-Nutzung die zur eigenen CUDA-Treiberversion
# passende Variante über die offizielle Installationsanleitung
# installieren (https://pytorch.org/get-started/locally/), z. B.
#   pip install torch --index-url https://download.pytorch.org/whl/cu121
# statt eines einfachen "pip install torch".
